# Projet Réseaux Télécom 2A ASR
Auteurs : *BEDROSSIAN Paul*, *BONGIOVANNI Arthur*

Sources et rapport du projet de réseaux de télécommunication. 
Ce projet avait pour but d'étudier les performances de différent algorithmes de routage dans un réseaux téléphonique commuté.
Dans le rapport ce trouve une analyse théorique de ces algorithme tandis que les différent fichier python font office de source pour la simulation et l'étude pratique de ces algorithmes.
Vous trouverez aussi une vidéo expliquant l'architecture et l'éxecution de la simulation ainsi que les résultats obtenu

## Lancer la simulation
 Pour lancer la simulation, il suffit d'éxécuter le fichiers "main.py". Pour ce faire veiller à télécharger les bibliotèques nécéssaires (matplotlib et networkx)
installation : `pip install -r requirements.txt`. Lancement (testé avec python 3.10.12): `python3 ./main.py`
